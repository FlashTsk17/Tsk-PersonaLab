# PersonaLab — Product Notes

## Purpose

PersonaLab is a lightweight self-reflection experience. It is not a clinical or psychological diagnostic tool.

## Initial experience

1. Introduce the experience.
2. Start the personality questionnaire.
3. Collect responses one question at a time.
4. Calculate a profile.
5. Present the result clearly.
6. Eventually allow signed-in users to revisit previous results.

## Initial profile model

The first version will use original profile categories designed for the product rather than reproducing a proprietary personality assessment.

Candidate profiles:
- Explorer
- Strategist
- Connector
- Builder

The scoring model will be implemented after the questionnaire flow is established.
