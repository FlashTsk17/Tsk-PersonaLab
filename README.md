# Tsk PersonaLab

> Discover yourself. Understand your personality.

Tsk PersonaLab is an interactive personality discovery web application built by **Tsk's Tech Services**.

The goal is to give users a simple, engaging way to answer a short questionnaire and explore a personal profile based on their responses.

## Product flow

Home → Questionnaire → Questions → Results → History

## Planned architecture

- Frontend: React + TypeScript + Vite
- Backend: Node.js + Express + TypeScript
- Persistence: database-backed result history
- Authentication: user accounts and protected history
- Testing: unit and integration tests

## Current status

Early development. The project is being built in stages.
